# Grill Me

這是 stateless / document-free 的 grilling 入口。

開始前讀並遵循 [grilling](../grilling/SKILL.md)。

適用：

- 不在 repository / working directory 中；
- 只想把想法、plan、decision 想清楚；
- 不希望修改 GLOSSARY / ADR。

如果工作發生在 code repository，且 resolved terminology / durable architecture decisions 應留下 paper trail，優先使用 grill-with-docs。

完成條件與 grilling 相同：decision frontier 為空，且使用者確認 shared understanding。
